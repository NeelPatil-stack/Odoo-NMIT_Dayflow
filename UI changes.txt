Redesign the **frontend only** of my Employee Management System named **कार्यसेतु (Kaaryasetu)** using the **same overall visual feel, color balance, spacing quality, animation smoothness, and premium SaaS experience seen on Hajiri’s website**, while keeping the design original and not directly copying their assets or code.

The goal is to make the website feel:

**clean, premium, modern, smooth, minimal, professional, slightly playful, and highly polished**

Do not change backend logic, database structure, or existing functionality unless required to connect frontend states correctly.

---

Website Name:

**कार्यसेतु**

Use Marathi prominently in the interface wherever suitable.

Use the existing **कार्यसेतु logo** in:

* Login page
* Sidebar
* Navbar
* Dashboard header

* Or responsive cards

---

# 34. STRICT LAYOUT RULES

Prevent UI formatting problems.

Never allow:

* Text overlapping icons
* Cards overlapping other cards
* Buttons overflowing containers
* Charts escaping cards
* Tables extending beyond viewport
* Fixed headers covering content
* Sidebar covering main content

Use proper:

* CSS Grid
* Flexbox
* `min-width: 0`
* Responsive breakpoints
* Overflow handling

Every card must respect its parent container.

---

# 35. ANIMATION PERFORMANCE

Use GPU-friendly properties:

* transform
* opacity

Avoid animating:

* width repeatedly
* height repeatedly
* top
* left
* box-shadow excessively

Support:

`prefers-reduced-motion`

Disable or minimize non-essential animations when reduced motion is enabled.

---

Do not redesign functionality unnecessarily.
